# Storyboard Previs Sheet

A reusable Codex skill for turning screenplay beats and timed video prompts into readable director's previs storyboard sheets.

## What it does

- Plans panels from explicit cuts, meaningful action beats, reactions, camera changes, and continuity states.
- Lets panel and page counts follow the material instead of forcing a fixed 12-panel layout.
- Preserves character references, source dialogue, timing, blocking, camera axis, and start/end states.
- Locks every page to one consistent graphite-pencil drawing style, with optional colored production annotations.
- Requires all visible storyboard lettering to be English, even when source material or references contain Chinese.
- Splits long sequences across legible pages with clear continuity handoffs.
- Inspects generated sheets for missing, duplicated, or out-of-order beats.

## Install

Copy this folder into your Codex skills directory, for example:

`~/.codex/skills/storyboard-previs-sheet/`

The skill entry point is `SKILL.md`.
